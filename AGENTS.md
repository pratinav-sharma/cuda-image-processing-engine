# Working on this project

- Keep commits focused, with short, friendly messages. Preserve existing work.
- For each implementation or evidence commit, update `docs/implementation-notes.md`
  in the same commit. Use its commit subject as the entry title; describe the
  problem, approach and tradeoffs, important files, actual validation, and an
  interview question. Add hashes later if useful; do not require a self-referencing hash.
- Explain CUDA changes for a beginner. Keep measured, inferred, failed, and unrun
  checks distinct. Preserve raw benchmark/profile evidence and timing boundaries.
- Ask before driver configuration changes or reboots. No CNN framework belongs
  in this project; the CNN is a separate future project.
